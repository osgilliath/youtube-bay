## Youtube Bay - A YT video downloader
A youtube video downloader, from the terminal.

Download youtube videos, in any format you want.

Arising from my need to download videos from youtube, and the insane trust I have on third party websites, so here is my program, where you can download youtube videos in either video or audio format, your wish is this program's command.

## Insructions

Download and run the [yt-bay.exe](yt-bay.exe)

- Tell the program what format you want the audio in
- Paste the video url
- Boom, Done! Easy af!!

> this .exe will only work in a windows system

for linux or mac based system use the [source code](yt-bay.py)

## For source code usage

To install the required libraries, run:
```bash
pip install imageio_ffmpeg
```

Then simply run the program:
```bash
python yt-bay.py
```

then repeat the same steps as the exe.
